# Release notes

## 0.1.0 — Phase A implementation

- Real PyAV RTSP TCP/UDP capture with bounded timeouts, latest-frame handoff,
  exponential reconnection and a pause after repeated explicit auth failures.
- Borderless always-on-top fullscreen Qt display, NO SIGNAL / CHANNEL ERROR
  states, hidden cursor, force reconnect and PIN-protected exit.
- Windows sleep prevention with restoration, secure local camera setup using
  Windows Credential Manager and sanitized rotating logs.
- Windows install/start/probe/optional sign-in startup scripts, automated tests
  and a genuine local MediaMTX/FFmpeg integration source.

Target-PC Phase A acceptance is pending. Phases B–F have not started.
